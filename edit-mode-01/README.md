# 編集モード実験（edit-mode-01）

実在のお客様のページとは無関係の、編集モードの実験一式です。
ページは架空のダミー店舗で、上部に「実験ページ」と表示されます。

## 中身
- `index.html` … 実験ページ。右下の「編集モード」ボタン→合言葉 `jikken` で、
  文字を直接書き換え、色と画像を変えられます。
- `admin.html` … 管理画面（実験）。フォームで文字・色・画像を直して保存します。
- `content.js` … 読み込み・保存の共通処理。`GAS_URL` が空の間は
  このブラウザの localStorage に保存します（実験の初期状態）。
- `gas/Code.gs` … スプレッドシートへ保存・読み出しをするGAS受け口。

## GASをつなぐ手順
1. 実験用のGoogleスプレッドシートを新規作成する
2. 拡張機能→Apps Script で `gas/Code.gs` を貼り付ける
3. `setupContentSheet()` を1回実行する（初回は承認画面が出ます）
4. デプロイ→ウェブアプリ（実行ユーザー＝自分／アクセス＝全員）でURLを発行する
5. `content.js` の `GAS_URL` にそのURLを貼って、ページを再公開する
6. ページと管理画面で、直した内容がシート経由で行き来するかを確認する

## 確かめること
- 編集モードで文字・色・画像を変えて保存→再読み込みで残っているか
- 管理画面で直した内容が、ページに反映されるか（逆も）
- GAS接続後、別のブラウザで開いても同じ内容が出るか
